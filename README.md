# CRM Decision Support System

## Overview
This project presents a CRM-based decision support system designed to improve lead analysis, data quality assessment, KPI reporting, and decision-making through SQL analytics and Power BI dashboards.

The project demonstrates how traditional tabular analysis can be transformed into more intuitive and actionable dashboard-based reporting for better operational insights.

## Objectives
- Build a structured data model for CRM/admissions-style analysis
- Perform SQL-based KPI and performance analysis
- Compare traditional tabular reporting with interactive Power BI dashboards
- Support decision-making through visualization and analytics

## Tools & Technologies
- SQL
- SQLite / relational database
- Power BI
- Excel / CSV
- Data modeling
- Dashboard design

## Project Structure
- `sql/` – database schema, data loading, KPI and analysis queries
- `dashboard/traditional_tabular_outputs/` – screenshots of traditional tabular reports
- `dashboard/powerbi_screenshots/` – screenshots of dashboard outputs
- `docs/` – project documentation and summary
- `images/` – ERD, workflow, architecture diagrams
- `data/` – sample dataset and data dictionary

## Key Features
- SQL-based KPI generation
- Traditional tabular analysis outputs
- Dashboard-based visualization in Power BI
- Comparison of manual reporting vs visual decision support
- Data quality and reporting improvement focus

## Traditional vs Dashboard Reporting
Traditional analysis often presents information in static tabular formats, which can be difficult to interpret quickly for decision-making.  
This project shows how the same analytical outputs can be converted into interactive visual dashboards that improve accessibility, monitoring, and strategic insight.
